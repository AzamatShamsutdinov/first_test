ИНСТРУКЦИЯ ПО ИНТЕГРАЦИИ С WORDPRESS
=====================================

Файл home.php теперь содержит динамический код для WordPress.

ВНЕСЕННЫЕ ИЗМЕНЕНИЯ:
--------------------

1. ✅ Заменено "Инструмент" на "Отопление" в заголовке
2. ✅ Изменен placeholder поиска на "Товары для уюта и тепла"
3. ✅ Категории теперь загружаются динамически из WordPress

КАК ИСПОЛЬЗОВАТЬ:
-----------------

1. Скопируйте файл home.php в вашу тему WordPress:
   wp-content/themes/ваша-тема/templates/home.php

2. Создайте категории товаров в WordPress (WooCommerce):
   - Перейдите в WooCommerce → Товары → Категории
   - Создайте нужные категории (Отопление, Котлы, Радиаторы и т.д.)

3. Если вы не используете WooCommerce, измените код на стандартные категории WordPress:
   Замените в файле:
   'taxonomy' => 'product_cat'
   на:
   'taxonomy' => 'category'

СТАНДАРТНЫЕ КАТЕГОРИИ (если WordPress категории не найдены):
------------------------------------------------------------

Если категории не настроены в WordPress, будут использоваться:
- Отопление
- Электрика и свет
- Котлы и печи
- Радиаторы
- Теплые полы
- Термостаты
- Трубы и фитинги
- Насосы
- Вентиляция
- Кондиционеры
- Обогреватели
- Климат-контроль
- Изоляция
- Аксессуары для отопления

НАСТРОЙКИ ДЛЯ КАТЕГОРИЙ:
------------------------

Категории автоматически берутся из WordPress/WooCommerce.
Вы можете управлять ими через админ-панель:
- Название категории
- Описание
- Изображение
- Порядок отображения (плагин Category Order)

ПРИМЕЧАНИЕ:
-----------

Убедитесь, что у вас установлены необходимые плагины:
- WooCommerce (если продаете товары)
- Category Order and Taxonomy Terms Order (для сортировки категорий)
